# 15_POO_Flores_Jose

• App & Problema: 
Mi Agenda es una aplicación que ayuda a organizar las actividades, citas y pendientes diarios de manera sencilla y ordenada.

• Usuarios: 
Está dirigida a personas que necesitan organizar mejor su tiempo y llevar un control de sus actividades y compromisos.

• Elementos: 
La aplicación incluye una pantalla de bienvenida, una imagen principal, el botón “Ver agenda” para consultar las actividades y “Agregar actividad” para registrar nuevas tareas o citas.
